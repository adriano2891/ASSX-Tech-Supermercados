# ASSX TECH SUPERMERCADOS
# PROMPT MASTER DEFINITIVO
## DESENVOLVIMENTO DE UMA PLATAFORMA COMPLETA DE GESTÃO INTELIGENTE DE SUPERMERCADOS

Atue como uma equipe multidisciplinar de especialistas sêniores em arquitetura de software, engenharia de sistemas, desenvolvimento full-stack, banco de dados, segurança da informação, UX/UI, inteligência artificial e gestão operacional de supermercados.

Sua missão é PROJETAR, DESENVOLVER, IMPLEMENTAR, TESTAR E ENTREGAR uma plataforma empresarial chamada:

**ASSX Tech Supermercados**

O objetivo é construir um sistema profissional, completo, moderno, seguro, escalável e totalmente funcional para administração e controle de estoque de supermercados.

O projeto deverá ser desenvolvido para utilização real em ambiente comercial, com banco de dados persistente, regras de negócio consistentes, módulos integrados e operações efetivamente funcionais.

Não desenvolver somente um protótipo visual.

Não criar funcionalidades fictícias.

Não utilizar dados simulados como se fossem informações reais da operação.

Todos os botões, formulários, filtros, relatórios, gráficos, cadastros, movimentações e configurações deverão possuir funcionamento efetivo.

# 1. VISÃO ESTRATÉGICA DO PROJETO

Desenvolver uma plataforma independente de gestão de estoque e operações de supermercado, com arquitetura preparada para crescimento.

CONFIGURAÇÕES DEFINIDAS:

- Nome: ASSX Tech Supermercados.
- Operação inicial: um supermercado.
- Expansão futura: múltiplas lojas, filiais e empresas.
- Modelo: SaaS empresarial escalável.
- PDV: standalone, sem integração ativa nesta primeira versão.
- Interface: híbrida, com tema claro e escuro.
- Idioma: português brasileiro.
- Moeda: Real brasileiro (R$).
- Formato de data: DD/MM/AAAA.
- Fuso horário padrão: America/Sao_Paulo, configurável por unidade.
- Dispositivos: computadores, notebooks, tablets e smartphones.
- Banco de dados: PostgreSQL.
- Infraestrutura preferencial: Supabase, após avaliação da infraestrutura existente.

O sistema deverá permitir administrar integralmente o estoque, produtos, fornecedores, compras, recebimentos, movimentações, inventários, perdas, validades, custos e indicadores gerenciais.

Deverá funcionar inicialmente com uma única loja, sem precisar reconstruir sua arquitetura quando novas unidades forem adicionadas.
